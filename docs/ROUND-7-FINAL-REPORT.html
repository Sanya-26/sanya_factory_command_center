Filter Behavior & UX Details

Filter Logic

All filters use AND logic (intersection, not union):

Example 1: Project="Pacific Pools" AND Status="blocked"
→ Shows only blocked tasks assigned to Pacific Pools

Example 2: Assignee="Mitanshi" AND Status="in_progress" AND Priority="urgent"
→ Shows only urgent in-progress tasks assigned to Mitanshi

Example 3: Clear all filters
→ Shows all tasks in the system

Filter Dropdown Options

Filter Default Label Options
Project "All projects (N)" Distinct company_ids
Assignee "All assignees (N)" Distinct assignee_ids with engineer names
Status "All statuses" open, in_progress, blocked, done
Priority "All priorities" urgent, high, normal

Progress Counting

The progress header (visible when collapsed) shows real-time counts across ALL issues, not just filtered ones:

"5 open · 2 in progress · 3 done"

This lets you see total team load at a glance, even with filters active.

Sorting

Tasks are sorted by:

  1. Status first — Open items at top, done at bottom
  2. Then priority — Urgent items before high/normal
  3. Then age — Newest items first (by created_at)
